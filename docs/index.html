OpenToDo

Simple tasks. Local files. No lock-in.

OpenToDo is a cross-platform desktop task manager built with C#/.NET 8 and Avalonia.

Project structure

  • Core — task models and interfaces.
  • Data — local JSON-backed storage.
  • Plugins — extension contract.
  • App — Avalonia desktop UI.

Development

Open OpenToDo.sln in Visual Studio with the .NET 8 SDK installed.
